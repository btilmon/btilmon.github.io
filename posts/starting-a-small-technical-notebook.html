Starting a small technical notebook

This site now has a place for notes that are too small for a paper, too useful to leave buried in a repo, and too specific to make sense as a polished project page.

I expect most posts here to be practical: calibrated capture details, 3D reconstruction observations, graphics experiments, implementation notes, and links to code when the code is the clearest explanation.

The format should stay simple. A short title, a useful summary, and the smallest amount of surrounding page needed to make the note readable.
